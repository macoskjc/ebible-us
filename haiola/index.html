Haiola

Haiola is a free, open-source Bible file format converter for Scripture publishers. Convert USFM, USFX, or Digital Bible Library bundles into formats your audience can actually use.

Free & Open Source

How It Works

Input Formats

  • USFM files — from Paratext, Bibledit, Adapt It, or any standards-compliant source
  • ETEN DBL bundles — from Digital Bible Library
  • USFX files — eBible.org USFX format

Output Formats

  • HTML — for web sites or offline browser reading
  • EPUB3 — with EPUB2 backward compatibility
  • Crosswire Sword modules — for Bible study software
  • Microsoft Word XML — WordML format
  • PDF — via XeLaTeX for print-quality output
  • USFX — normalized for DBL submission
  • BiblePay app format
  • Scripture App Builder format
  • MySword format

Features

Multi-Format Conversion

One tool handles the full pipeline from raw USFM to distributable formats for web, mobile, and print.

DBL Normalization

Normalize USFM files to meet ETEN Digital Bible Library submission standards.

Open Source

Fully open source. Fork it, contribute, or adapt it for your organization's workflow.

Unicode Support

Full Unicode support for all scripts and writing systems — handles any language eBible.org publishes.

Free to Use

No license fees, no usage restrictions. Built to remove barriers between Bible translators and the people they serve.
